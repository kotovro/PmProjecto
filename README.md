## Внешние ресурсы
Разработка, её текущий статус, беклог и задачи находятся в [таск-трекере](https://ru.yougile.com/board/ojpiy9m2d6oh) (проект PM). В нем представлены задачи всех фаз с исполнителями, сроками, оценками и затраченным временем

## Навигация по репозиторию

| Папка | Фаза | Содержание |
|-------|------|------------|
| [`phase1/`](./phase1/) | Фаза 1. Выбор концепции проекта | концепции и критерии, экспертные оценки, нечёткий коллективный TOPSIS, чёткий коллективный MAI |
| [`phase2/`](./phase2/) | Фаза 2. Распределение работы | декомпозиция фазы 3, оценки трудоёмкости и предпочтений, задача о назначениях и её решение |
| [`phase3/`](./phase3/) | Фаза 3. Оценка проекта | use case, COSMIC FP, UCP, коллективная экспертная оценка, выводы о масштабе |
| [`phase4/`](./phase4/) | Фаза 4. Прогнозирование | трёхточечные оценки задач фазы 5, две модели Монте-Карло |
| [`phase5/`](./phase5/) | Фаза 5. Планирование | задачи, ресурсы, предшествование, эвристики упорядочения, календарный план |
| [`report/`](./report/) | Отчёты по фазам и итоговый отчет | Итоги каждой из фаз|

## Статус

- **Фаза 1**: готова. Добавлены файлы с расчётами [TOPSIS](./phase1/topsis.xlsx) и [MAI](./phase1/mai.xlsx); добавлен [отчет](./report/Отчёт%20по%20лабораторной%20работе%201.docx), в рамках которого рассматриваются результаты по TOPSIS и MAI и приведено решение относительно проекта, который будет прорабатываться дальше. На основании методов принято решение прорабатывать разработку чат-бота.
- **Фаза 2**: в разработке. Добавлен [файл](./phase2/tasks_assignament.py) с расчетом функции, показывающей загруженность участников; результаты по загруженности на третью фазу представлены в [разделе](./phase2/results)
- **Фаза 3**: в разработке. В сводном [отчете](./report/Отчёт%20по%20Фазе%203-%20Оценка%20проекта.docx) рассмотрены варианты использования и трудозатраты на их реализацию,  от какой функциональности потенциально можно отказаться.
